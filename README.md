LangGraph Practice Programs 🚀
A collection of hands-on Python projects exploring LangGraph, ranging from basic graph architectures to multi-agent iterative workflows.

📂 Project Structure & Contents
1. Introduction to LangGraph (app.py & basic_code.ipynb)
app.py: A basic "Hello World" style introductory script for LangGraph.

basic_code.ipynb: The foundational code covering core LangGraph concepts, including how to initialize graphs, define nodes, add edges, and set entry/exit points (START and END).

2. Prompt Chaining (prompt_chaining.ipynb)
Introduces a sequential, linear workflow pattern using prompt chaining.

3. Quadratic Equation Solver (quadratic_eq.ipynb)
Demonstrates a conditional workflow implementation.

Solves quadratic equations dynamically using programmatic logic (without relying on an LLM).

4. AI-Powered Social Media Post Generator (post_generator.ipynb)
An iterative multi-agent workflow leveraging multiple LLMs.

How it works: You provide a target topic and platform, and the system collaborates to write, evaluate, and refine posts tailored to that specific platform.

🛠️ Tech Stack
Python

LangGraph / LangChain

Google Gemini API (or configured LLM provider)
